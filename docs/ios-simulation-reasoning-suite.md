# iOS 模拟推理测试套件

## 测试目的

这套用例评估的是对话级溯因推理（abductive/simulation reasoning），不是 Rime 拼音解码，也不是候选词频排序。模型需要从行为异常、隐喻、矛盾和生活细节中推断最可能的隐藏背景，同时报告证据和不确定性。

## Input Playground 使用方式

1. 打开 Input Playground；
2. 将整段对话粘贴到输入框；
3. 点击“模拟推理”；
4. iOS 26 使用本机 Foundation Models；
5. iOS 17/18 显示不可用，不上传对话，也不影响普通输入和 Rime/Core ML 候选推理。

## 输出契约

```json
{
  "hidden_behavior": "最可能的隐藏行为",
  "evidence": ["异常线索 1", "异常线索 2"],
  "motivation": "隐瞒的可能动机",
  "confidence": 0.0,
  "uncertainties": ["仍不能确定的部分"]
}
```

评测时必须分别检查：隐藏事实是否命中、证据是否来自原对话、动机是否有证据支撑、置信度是否过高、是否明确列出不确定性。

## 组别 A：中文

隐藏设定：乙在衣柜中秘密照顾一只暴雨中受伤、闯入家中的小黄猫；乙担心甲讨厌动物毛发，所以用整理衣物、白噪音、减脂餐等理由掩饰。

关键证据包括：暴雨、猫叫、热牛奶和鸡胸肉、黄色湿毛、抓碎的报纸、衣柜尾巴、乙阻止甲开门，以及最后直接承认救助受伤小猫。

## 组别 B：全拼音

将同等复杂度的对话输入为无声调全拼音，先经过 Rime/拼音归一化，再送入模拟推理层。预期隐藏设定：B 在厨房/箱子中偷偷救助被车撞伤的流浪黑狗；B 因担心 A 把狗赶出去而编造出差、风声、玻璃杯划伤等解释。

拼音组允许存在同音歧义、错别字或中英混入；评测重点是模型能否利用整段上下文恢复逻辑主线，而不是逐字纠正每个音节。

## 评测等级

- **通过**：隐藏行为、至少 3 条有效证据、动机基本命中，并明确不确定性；
- **部分通过**：隐藏行为命中，但证据链不完整或动机过度推断；
- **失败**：只复述表面内容、把借口当事实、或给出对话之外的确定结论。

模拟推理只在主 App/Playground 执行；键盘扩展继续使用 Rime + Core ML 候选重排，避免把长对话和大模型会话放入每次按键路径。
