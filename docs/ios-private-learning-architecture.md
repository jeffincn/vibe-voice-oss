# iOS 本地对话学习与隐私架构

## 目标与边界

系统要支持三种用途：

1. 当前输入的即时上下文推理；
2. 用户自己的语言风格摘要，用于本地 Core ML/Rime 重排；
3. 用户明确同意后，导出样本用于资料上传或离线训练。

默认策略是“不上传、不保存原文、不让键盘扩展直接拥有可读语料”。“混淆”不能替代加密：需要使用 CryptoKit 的认证加密、iOS Data Protection 和 Keychain 密钥隔离。

## 数据分层

| 层级 | 数据 | 保存位置 | 默认保留 | 键盘扩展是否可读 |
|---|---|---|---|---|
| L0 | 当前光标前后最多 240 字符 | 内存 | 当前输入会话 | 是，短时使用 |
| L1 | 语言/脚本偏好、词频桶、领域标签、接受率 | App Group 中的摘要文件 | 长期 | 是，只有摘要 |
| L2 | `pinyin + acceptedText + boundedContext` 样本 | 主 App 私有容器的加密数据库 | 30 天或 5,000 条 | 否 |
| L3 | 用户审核后的导出包 | 用户选择的位置 | 一次性 | 否 |

L2 不应放入 App Group 明文。键盘需要贡献样本时，只能写入“应用公钥加密后的密文信封”；私钥只存在主 App 的私有 Keychain，扩展无法解密。

## 密钥设计

### 本地样本密钥

- 主 App 首次启用学习时生成 256-bit `Curve25519.KeyAgreement.PrivateKey`。
- 私钥存主 App 私有 Keychain，属性使用 `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`；不放入 UserDefaults、plist、App Group 或模型资源。
- 公钥可以放进 App Group，供键盘扩展加密待处理样本。
- 扩展为每条样本生成临时 Curve25519 密钥，与 App 公钥做 ECDH，再用 HKDF 派生 AES-GCM 密钥。
- 密文信封至少包含：`version`、临时公钥、随机 nonce、ciphertext、authentication tag、recordID、createdAt。
- associated data 绑定 `recordID + schemaVersion + purpose`，防止密文被调包或跨用途重放。
- 私钥轮换时保留旧版本只到已解密迁移完成；用户“删除学习数据”时删除私钥，使全部 L2 密文不可恢复。

### 文件层保护

数据库、导出临时文件和模型学习缓存使用 `URLFileProtection.complete`；若必须在首次解锁后可访问，则明确使用 `completeUntilFirstUserAuthentication`。iOS Data Protection 会对磁盘文件自动加密，但它不能替代应用层 AES-GCM 的访问隔离。

## 样本格式

解密后的逻辑结构示例：

```json
{
  "schema": 1,
  "id": "uuid",
  "createdAt": "2026-07-26T12:00:00Z",
  "appClass": "messaging",
  "language": "zh-Hans-pinyin",
  "preedit": "hao",
  "acceptedText": "好",
  "contextBefore": "这个方案很",
  "contextAfter": "，我们继续",
  "redaction": ["email", "phone"],
  "consentRevision": 3
}
```

实际实现中，`contextBefore/contextAfter` 应先做本地脱敏，再进入密文：URL、邮箱、电话号码、银行卡号、身份证号替换为类型 token；密码框、一次性验证码、支付字段和用户标记为“私密应用”的输入不采集。

## L1 风格摘要

L1 只保留不能直接还原原文的统计量，例如：

- 简体/繁体/注音/拼音比例；
- 常用词的计数桶（使用 keyed hash，不保存原词）；
- 标点和空格习惯；
- 平均句长、接受候选率、改写率；
- 可选领域分布（工作、技术、日常等）；
- 量化后的本地 embedding（必须单独加密，且不从 embedding 反解原文）。

L1 只用于候选排序，不应直接作为可导出的聊天记录。对每个用户设置上限和衰减，例如 90 天指数衰减、每个 hash 桶最多 100 次，降低长期重建风险。

## 读取与写入流程

## 未授权与部分授权降级

键盘必须在任何授权状态下保持基本输入可用：

| 状态 | 对话上下文 | Core ML 增强 | 学习写入 | 行为 |
|---|---|---|---|---|
| 完全访问 + 普通字段 | 允许 | 允许 | 按用户模式 | 完整上下文推理 |
| 未允许完全访问 | 禁止 | 禁止 | 禁止 | 仅 Rime 离线输入 |
| 安全输入框 | 禁止 | 禁止 | 禁止 | 仅基础输入，不记录数据 |
| 共享容器/Keychain 不可用 | 禁止持久化 | 禁止 | 禁止 | Rime 仍可输入 |
| Core ML 模型不可用 | 可按授权读取但不使用 | 禁止 | 可按模式记录 | Rime + 普通候选顺序 |

降级必须是 fail-closed：权限不足时不尝试绕过系统、不读取 App Group 历史数据、不写入 UserDefaults 学习计数、不联网。状态栏显示“基础模式：未允许完全访问”或“安全输入：仅保留基础输入”，用户仍可继续中英文输入。

### 键盘扩展

1. 从 `UITextDocumentProxy` 读取光标附近上下文；只保留内存窗口。
2. 使用 L1 摘要和当前 Rime 候选执行 Core ML 重排。
3. 用户确认候选后，构造最小样本；先脱敏，再用 App 公钥加密。
4. 将密文写入 App Group 的短期 inbox；扩展不读取旧样本、不解密旧样本。
5. 达到大小上限后停止写入并提示主 App 整理。

### 主 App

1. 用户打开“本地学习”页面后，解密并验证密文信封。
2. 写入主 App 私有加密数据库，成功后删除 App Group inbox 密文。
3. 更新 L1 摘要；训练任务只读取解密后的内存批次，完成后清零。
4. 训练产物只保留 Core ML 权重和摘要，不把原文写回模型日志。

## 上传/导出流程

绝不后台自动上传。用户必须逐步确认：

1. 选择时间范围和应用类别；
2. 显示将要导出的条数、字段和脱敏预览；
3. 允许逐条删除或编辑；
4. 用服务器公钥再次封装导出包，或导出到用户选定的文件位置；
5. 记录 consent revision、导出时间和撤回入口。

上传包不应包含设备标识、完整 Bundle ID、原始文档位置或键盘按键时间序列。服务器端只接受经过版本校验的 schema，并支持用户按 exportID 删除。

## 必须提供的设置

- 本地学习：关闭/开启；
- 当前 App 暂停学习；
- 仅保存风格摘要，不保存原文样本；
- 清除所有本地学习数据（包括 L1、L2、模型缓存和密钥）；
- 查看/编辑/导出样本；
- 永不上传（默认）；
- 允许在 Wi-Fi/充电时进行本地训练（默认关闭）。

## 安全验收

- App Group 中搜索不到可读的中文对话原文；
- 没有主 App 私钥时，L2 密文无法解密；
- 删除学习数据后旧密文不可恢复；
- 锁屏期间使用 `complete` 文件保护无法读取数据库；
- 密文修改一个字节会触发 AES-GCM 验证失败；
- 关闭学习后，键盘不再产生新的 inbox 记录；
- 密码/支付/私密应用测试不会产生样本；
- 无网络时所有本地推理仍可用；
- 导出前始终显示脱敏预览并要求用户确认。
