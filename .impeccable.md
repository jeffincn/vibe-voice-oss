## Design Context

### Users
Mac power users who want fast, private voice input in any application while staying focused on the field under the cursor. The primary job is push-to-talk dictation through a local oMLX ASR model with immediate, trustworthy state feedback.

### Brand Personality
Quiet, precise, native. The interface should feel like a small piece of macOS system chrome: confident and responsive, never playful, loud, or attention-seeking.

### Aesthetic Direction
Refined minimalism with a compact interpretation of the supplied Siri orb reference: a randomized cyan/magenta particle sphere with symmetric side waveforms floating directly over the desktop on a fully transparent window. Each particle has an independent deterministic trajectory, avoiding repetitive petal or butterfly motion. The spectrum moves only in response to real voice input; autonomous motion is reserved for transcribing. Avoid container backgrounds, decorative gradients elsewhere, glass-heavy decoration, text-heavy overlays, large controls, and generic dashboard styling.

### Design Principles
1. Preserve focus: overlays never activate, accept input, or move the user's cursor.
2. Communicate state through one signature motion: a voice-reactive fluid spectrum while recording and measured ambient flow while transcribing.
3. Stay noticeable without obstructing work: use a confident but bounded footprint and dismiss immediately when the task finishes.
4. Feel native: use macOS window behavior, system accessibility preferences, and 60fps-friendly drawing.
5. Remain accessible: status must not rely on color, and reduced-motion mode uses stable, non-looping feedback.
